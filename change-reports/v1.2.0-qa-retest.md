## Scenarios Tested

### 1. Settings Menu (Alt+Shift+R)

**Status:** ✅ Pass

- Opens centered modal with entrance animation
- Status bar shows "● Inactive" (grey) when auto-refresh is off
- Status bar shows "● Active · refreshing every N seconds/minutes" (green) when on
- **Sections properly grouped:** REFRESH (3 items), GENERAL (1 item), WATCHES (variable)
- All buttons show emoji icon, title, subtitle description, and inline value
- Toggle switch renders correctly (grey OFF / blue ON)
- Footer shows `Press Alt+Shift+R to open this menu · v1.2.0`
- **[NEW]** Version number displayed in footer ✅
- Keyboard: Escape closes modal, hotkey toggles modal

### 12. Keyboard Navigation

**Status:** ✅ Pass

| Key | Context | Behavior | Result |
|-----|---------|----------|--------|
| `Alt+Shift+R` | Any | Opens/toggles settings modal | ✅ |
| `Escape` | Settings | Closes settings modal | ✅ |
| `Escape` | Sub-modal | Returns to settings (not close all) | ✅ |
| `Escape` | Element picker | Cancels picker, returns to page | ✅ |
| `ArrowDown` | Any modal | Moves focus to next button (white outline) | ✅ |
| `ArrowUp` | Any modal | Moves focus to previous button | ✅ |
| `Enter` | Any modal | Activates focused button | ✅ |
| Wraparound | Settings | Last item → first item on ArrowDown | ✅ |
| `Alt+Shift+R` | Sub-modal | Closes sub-modal, reopens settings | ✅ |
