## Bug Fixes

### Bug #1: Timer resumes in sub-modals (Medium)
**Problem:** Opening a sub-modal (Refresh Interval, Badge Position, Font Size, Hotkey, Stop Alert, Inspect Watches, Remove Watches) from Settings un-paused the refresh timer. The `close()` callback called `resumeRefresh()` during the modal transition, meaning the page could auto-refresh while the user was actively configuring settings.

**Fix:** Changed all `close()` calls in `openSettingsMenu` sub-modal transitions to `close(true)`, passing `skipOnClose = true` to bypass the `resumeRefresh` callback. The timer stays paused from the initial `pauseRefresh()` until the user explicitly closes the final modal.

**Files changed:** `auto-refresh.user.js` — 7 locations in `openSettingsMenu()`  
**Verification:** ✅ Tested in browser — badge showed `⏸ 7s` when navigating into Refresh Interval sub-modal. Timer remained paused throughout sub-modal flow.

### Bug #2: Interval change lost on refresh (Low)
**Problem:** If the timer fired while a sub-modal was open (consequence of Bug #1), the page refreshed before `GM_setValue` completed, losing the user's selection.

**Fix:** Resolved automatically by Bug #1 — timer can no longer fire during sub-modal configuration.

**Verification:** ✅ No longer reproducible.

### Bug #3: Body watch captures inline scripts (Low)
**Problem:** Watching `<body>` via Text Content mode captured `textContent` which includes all inline `<script>` and `<style>` content, creating unreadable diffs.

**Fix:** Changed all 5 instances of `el.textContent.trim()` to `el.innerText.trim()` for watch content capture and comparison. `innerText` excludes `<script>` and `<style>` content by spec.

**Files changed:** `auto-refresh.user.js` — lines ~1105, 1295, 1337, 1534, 1620  
**Verification:** ✅ Code-verified. `innerText` is the correct API for user-visible text.

## Improvements

### 1. Version Metadata
- Added `VERSION` constant (`'1.2.0'`)
- Bumped `@version` in userscript metadata from `1.0` to `1.2.0`
- Settings footer now shows version: `Press Alt+Shift+R to open this menu · v1.2.0`
- **Verified:** ✅ Footer displays `v1.2.0` in browser

### 2. Badge ARIA Accessibility
- Added `role="button"` and `aria-label="Auto-refresh countdown badge — click for options"` to the badge element
- Badge now properly identified as a clickable button in accessibility trees
- **Verified:** ✅ Accessibility snapshot shows `button "Auto-refresh countdown badge — click for options"`

### 3. Badge Minute Format
- Changed time display from `X:XX` (e.g., `1:56`) to `Xm XXs` (e.g., `1m 56s`) for intervals ≥60s
- Applied in both `updateBadge()` (line 213) and Quick Actions status bar (line 326)
- **Verified:** ✅ Badge shows `↻ 1m 56s` with 2-minute interval. Screenshot confirmed.

### 4. Toast Stacking
- Replaced single `auto-refresh-toast` ID with counter-based unique IDs (`auto-refresh-toast-${toastCounter}`)
- Existing toasts shift down by 48px when a new toast appears
- Added `top .3s` transition for smooth vertical movement
- Toast lifetime is 3 seconds
- **Verified:** ✅ Code-verified. MCP too slow to visually capture overlapping toasts, but implementation follows correct stacking pattern.

### 5. Truncated Long Diffs
- Added `DIFF_LIMIT = 500` character threshold in Watch Inspector content diff display
- When diff exceeds limit, text is truncated with `…` suffix
- "Show full diff (N chars)" expand button appears below truncated text
- Diff box constrained to `max-height:200px;overflow-y:auto` to prevent modal overflow
- **Verified:** ✅ Code-verified. Test page counter element produces small diffs; truncation activates only on content-heavy pages.

### 6. Large Element Warning
- In element picker mode selection modal, checks `el.innerText.trim().length > 1000`
- Shows amber warning: "⚠ This element has N chars of text. Consider picking a more specific child element for cleaner diffs."
- Warning uses amber styling (`#332b00` background, `#ffcc00` border)
- **Verified:** ✅ Code-verified. Test page `#counter` element too small to trigger; activates on large elements like `<body>`.
