High-Level Overview

Auto Refresh is a Tampermonkey/Greasemonkey userscript that provides automatic page refreshing, DOM element watching with change detection, webhook notifications, TTS alerts, and a full settings UI — all rendered inside an isolated Shadow DOM.

Architecture Patterns

①
Singleton Services
IIFE-constructed singletons with private state and public API

Config, WatchStore, WebhookService, RefreshService, and Modal are all immediately-invoked function expressions that return an object with a curated public API. Private helper functions and state are fully encapsulated.

②
Pub/Sub Event Bus
Decoupled communication via EventBus.on() / .emit()

Components never directly call each other for state changes. Instead, services emit domain events (config:changed, watch:added) and consumers subscribe. A Map of Sets stores listeners; on() returns an unsubscribe function.

③
Modal Stack Navigation
Stack-based push/pop/replace with breadcrumb trail

The Modal framework maintains a stack[] of entries. push() slides in a new panel, pop() returns to the parent, and replace() swaps at a given depth. At depth ≥ 2, a clickable breadcrumb trail appears. Animated transitions with reduced-motion support.

④
DOM Builder — h()
Lightweight virtual-DOM-like element factory

h(tag, props, ...children) creates DOM elements in a JSX-like style. Props support class, style, text, html, event listeners, and arbitrary attributes. Reduces boilerplate compared to raw createElement.

⑤
Schema-Driven Config
CONFIG_SCHEMA defines all settings with defaults & types

Every setting is declared in a schema: { key, default, type }. Config.get(name) reads with type-safe default, Config.set(name, value) writes and emits config:changed. GM storage key names are centralized in the schema.

⑥
CSS Custom Properties
Theme colors as --ar-* variables in Shadow DOM

All theme colors are injected as CSS custom properties in a <style> tag inside the shadow root. .ar-* utility classes reference them via var(--ar-xxx). Theme switch = update one style element → all UI updates instantly.

⑦
Reactive Modal Rebuild
Modals declare reactsTo events and auto-refresh

Modal definitions can include reactsTo: ['watch:added', ...]. When one of those events fires while the modal is active, Modal.refresh() re-invokes the build() function, achieving real-time UI updates without manual wiring.

⑧
Focus Trap
Keyboard-accessible modal navigation with arrow keys

createFocusTrap(container) intercepts arrow keys and Enter within a modal panel. Up/Down cycles through focusable buttons, Enter activates. A visible outline follows the focused element. Prevents focus from leaking to the page behind the modal.

Bootstrap Flow

What happens when the userscript loads, in order:

1. Constants defined — T (colors), THEMES, CORNERS, CONFIG_SCHEMA, I18N dictionaries
↓
2. Core singletons constructed — EventBus, State, Config, WatchStore
↓
3. Shadow DOM created — #auto-refresh-shadow-host attached to documentElement
↓
4. CSS injected — theme vars <style> + all .ar-* classes <style>
↓
5. Badge created — position, font size, theme, opacity applied
↓
6. Modal.define() — 20+ modal definitions registered (lazy, built only on open)
↓
7. Event listeners — hotkey (keydown), context menu (Ctrl+right-click), cheat sheet (?)
↓
8. GM_registerMenuCommand() — 9 Tampermonkey menu items
↓
9. onPageReady() — when readyState === 'complete': start refresh if enabled, run checkForChanges()

EventBus

⚡
EventBus
L68–83
Lightweight pub/sub system. Map of Set-based channels for decoupled inter-component communication.

API

  • EventBus.on(event, fn) → returns unsubscribe function
  • EventBus.off(event, fn) → removes specific listener
  • EventBus.emit(event, data) → fires all listeners for event

State

State Store
L85–97
Global mutable state for runtime references that don't persist across reloads.

Tracked Keys

  • alertIntervalId — setInterval ID for alert beep loop
  • audioCtx — AudioContext instance for beep synthesis
  • lastWebhookTime — timestamp for rate-limiting webhooks

WatchStore

👁
WatchStore
L1056–1240
Persists and synchronizes watch lists per URL. Supports cross-domain access via GM_listValues().

Public API

  • getLocal() → watches for this page (with migration)
  • setLocal(arr) → save watches for this page
  • add(w) → add watch, emit watch:added
  • remove(id) → remove watch by ID, emit watch:removed
  • getAll() → ALL watches across all domains (reads GM_listValues)
  • reSnapshot(w) → re-capture content/style snapshot for a watch
  • getStatus(w) → check if watched element exists & has selector
  • groupByDomain(watches) → organize by origin → pathname → watch[]
  • isWatchEnabled() / setWatchEnabled(val) → per-page watch toggle
  • clearAll() → remove all watches, emit watches:cleared

Storage Keys

  • autoRefreshWatches_{origin}{pathname} — JSON array
  • autoRefreshWatchEnabled_{origin}{pathname} — boolean

Migration

_migrate() auto-assigns IDs & URLs to legacy watches. Runs on first load from cache.

WebhookService

🔗
WebhookService
L2202–2235
Multi-webhook management with format-specific payloads and rate limiting.

Public API

  • getConfig() → returns { globalEnabled, webhooks[] }
  • saveConfig(config) → persist webhook config
  • validateUrl(url) → checks URL format validity
  • addWebhook(config, {}) → add new webhook entry
  • updateWebhook(config, id, updates) → update by ID
  • deleteWebhook(config, id) → remove by ID
  • formatPayload(format, details, template) → build request body
  • send(details) → send to all enabled webhooks
  • sendTest(config) → send test notification

Supported Formats

Slack, Discord, Teams, Generic JSON. Template tags: {{url}}, {{selector}}, {{mode}}, {{summary}}, {{old_content}}, {{new_content}}, {{timestamp}}.

Rate limit: 30 seconds minimum between sends.

RefreshService

RefreshService
L2237–2246
Facade for the countdown timer, refresh toggle, and pause/resume logic.

Public API

  • start() → begins countdown timer (1s ticks), reloads at 0
  • stop() → clears timer, resets badge

Badge Urgency Colors

Green (>25% remaining) → Yellow (10–25%) → Red (<10%)

Shadow DOM

🔮
Shadow DOM Isolation
All UI lives inside a Shadow DOM attached to #auto-refresh-shadow-host.

A fixed-position host element is attached to document.documentElement with attachShadow({ mode: 'open' }). Inside:

  • Theme vars — <style> element with :host { --ar-bg: ...; }
  • CSS classes — <style> with 100+ .ar-* utility classes
  • Badge — countdown display with progress bar
  • Modal backdrop — shared overlay for all modal panels
  • Toast container — notification toasts
  • Context menu — Ctrl+right-click quick watch menu

Z-index: 2147483647 (max) ensures UI is always on top. pointer-events controlled dynamically.

Modal Framework

📋
Modal Stack Engine
L2248–2645
Declarative modal definitions with stack-based navigation, breadcrumbs, transitions, and focus trapping.

Core API

  • Modal.define(id, def) — register a modal definition (lazy)
  • Modal.open(id, extra) — close all, then show modal
  • Modal.push(id, extra) — push new modal onto stack (slide transition)
  • Modal.pop() — pop top modal, return to parent
  • Modal.replace(id, extra, depth) — replace at depth (used by TTS sub-pickers)
  • Modal.closeAll() — close entire stack with animation
  • Modal.refresh() — rebuild active modal's content
  • Modal.isOpen() / currentId() / hasInStack(id)

Definition Shape

  • title — header text (string or function)
  • build(panel, ctx) — populate the panel DOM
  • reactsTo — array of EventBus events that trigger rebuild
  • type: 'picker' — auto-generates option grid from options()
  • width — CSS max-width for the panel

Transitions

  • Push: current slides left + fades out, new slides in from right
  • Pop: current slides right + fades out, parent slides back from left
  • Close-all: final panel scales down + fades out
  • Respects prefers-reduced-motion

Badge

Badge Component
L1600–1771
Countdown display with urgency colors, progress bar, watch dot, and hover expansion.

Visual Elements

  • Countdown text — ↻ XmYs or ⏸ XmYs when paused
  • Progress bar — 3px bottom bar, width = remaining/total %, color matches urgency

Theming & CSS

🎨
Theme System
L130–195, L1276–1412
4 themes via CSS custom properties. Instant switching by updating one <style> element.

Available Themes

ThemeDescription
darkDefault — dark background, blue accent
lightLight background, dark text
minimalSubtle, low-contrast dark
highContrastMaximum contrast for accessibility

Mechanism

buildThemeVars(theme) generates CSS like :host { --ar-bg: #0d1117; --ar-text: #c9d1d9; ... }. On theme switch, only the content of one <style> tag is replaced. All .ar-* classes reference var(--ar-xxx) tokens. The helper v(token) produces var(--ar-{token}).

CSS Classes

100+ utility classes: .ar-btn, .ar-panel, .ar-toggle-track, .ar-grid-3col, .ar-toast, etc. All built by buildCss().

I18N — Internationalization

🌐
I18N System
L240–1012, L1014–1053
~300+ translation keys, en + es, with pluralization and auto-detection.

How It Works

  • t(key, params) — translation function, interpolates {param} placeholders
  • Pluralization via "singular|plural" format with {count} param
  • _resolveLanguage() — checks Config.get('language'): 'auto' detects from navigator.language
  • Fallback: unknown key in non-en → warn + return en version

Supported Languages

en (English), es (Spanish), auto (detect from browser)

Element Picker

🎯
Element Picker & Context Menu
L4492–4680
Visual element selector with highlight overlay + Ctrl+right-click quick watch creation.

Element Picker Flow

  • Overlay covers document with invisible listener
  • On mousemove → highlight target element with border + semi-transparent background
  • On click → generate CSS selector via getUniqueSelector(el)

Alerts & TTS

🔊
Alert System
L1879–2005
Beep synthesis via Web Audio API + TTS via SpeechSynthesis API. Three modes: beep, speech, both.

Alert Modes

  • beep — playBeep() using AudioContext oscillator, loops via startAlert()
  • speech — speak(text) using speechSynthesis.speak(), configurable voice/rate/volume
  • both — beep + speech simultaneously

TTS Configuration

  • Voice picker — lists all browser voices, grouped by language, filterable
  • Rate — 0.7× to 1.6× speed
  • Volume — 0.25 to 1.0
  • Preview — previewSpeak() plays sample with current or overridden settings
